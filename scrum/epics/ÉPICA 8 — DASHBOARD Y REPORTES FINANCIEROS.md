# ÉPICA 8 — DASHBOARD Y REPORTES FINANCIEROS

Construye el dashboard financiero completo.

## Objetivo

Crear una vista que permita entender rápidamente la situación financiera del hogar.

## Dashboard

Mostrar:

### Resumen

- ingresos;
- gastos;
- balance;
- dinero disponible;
- deuda total;
- ahorro;
- metas.

### Gráficos

Utilizar Chart.js.

Crear:

1. Gastos por categoría.
2. Ingresos vs gastos.
3. Evolución mensual.
4. Evolución de deuda.
5. Progreso de metas.

## Comparación

Permitir comparar:

- mes actual;
- mes anterior;
- últimos 3 meses;
- últimos 6 meses;
- año.

## Insights

Crear indicadores sencillos:

> Alimentación aumentó 18% respecto al mes anterior.

> Transporte representa 12% de tus gastos.

> Este mes gastaste $150.000 menos.

No generar recomendaciones financieras peligrosas ni asumir información que no exista.

## Reportes

Permitir exportar:

- CSV inicialmente.

Preparar arquitectura para PDF posteriormente.

## Mobile

El dashboard debe ser perfectamente usable en celular.

Evitar demasiados gráficos simultáneos.

Priorizar información importante.
