# ÉPICA 10 — UX MOBILE Y PWA

Optimiza la aplicación para uso diario desde teléfonos.

## Objetivo

Que registrar un gasto desde el celular sea tan sencillo como enviar un mensaje.

## Mobile

Optimizar:

- navbar;
- botones;
- formularios;
- tablas;
- gráficos;
- dashboard.

## Acciones rápidas

Crear botón flotante:

> +

Con opciones:

- gasto;
- ingreso;
- transferencia;
- aporte a meta;
- pago de deuda.

## PWA

Preparar Progressive Web App si es compatible con la arquitectura y hosting.

Implementar:

- manifest;
- iconos;
- instalación en pantalla principal;
- comportamiento responsive.

No implementar offline complejo inicialmente.

## UX

Reducir pasos.

Usar:

- selects inteligentes;
- valores recientes;
- categorías frecuentes;
- cuentas frecuentes.

Ejemplo:

Si Ronaldo suele registrar:

> Mercado → Davivienda

el sistema puede recordar la última selección.

No utilizar IA todavía.
