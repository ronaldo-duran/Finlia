# ÉPICA 1 — FUNDACIÓN Y CONFIGURACIÓN DEL PROYECTO

Utilizando el contexto del PROMPT MAESTRO, implementa la primera épica del proyecto.

## Objetivo

Crear la base técnica de la aplicación de finanzas familiares.

## Alcance

Implementar:

### 1. Proyecto Laravel

Crear/configurar correctamente el proyecto Laravel.

Configurar:

- PHP.
- Laravel.
- MySQL.
- `.env`.
- `.env.example`.
- timezone Colombia.
- locale español.
- configuración monetaria inicial COP.

### 2. Git

Preparar el repositorio:

- `.gitignore`.
- README inicial.
- estructura adecuada para GitHub.

### 3. Base de datos inicial

Crear únicamente las estructuras necesarias para:

- users.

No crear todavía todas las tablas futuras.

### 4. Autenticación

Implementar:

- registro;
- login;
- logout;
- recuperación de contraseña si es compatible con la arquitectura elegida;
- protección de rutas privadas.

### 5. Layout

Crear:

- navbar;
- sidebar responsive;
- menú móvil;
- footer;
- sistema de mensajes flash;
- página dashboard inicial.

### 6. Diseño

Utilizar Bootstrap 5.

Crear una interfaz:

- limpia;
- moderna;
- responsive;
- mobile-first.

### 7. Dashboard inicial

Crear un dashboard vacío pero preparado para futuras estadísticas.

Mostrar:

- bienvenida;
- usuario autenticado;
- fecha actual;
- estado inicial de la aplicación.

## Restricciones

No implementar todavía:

- gastos;
- ingresos;
- deudas;
- tarjetas;
- presupuestos;
- metas;
- familias.

Eso corresponde a futuras épicas.

## Entregables

Al finalizar:

1. Proyecto Laravel funcional.
2. Login funcionando.
3. Registro funcionando.
4. Dashboard protegido.
5. Base de datos funcionando.
6. README inicial.
7. `.env.example`.
8. Tests básicos.
9. Instrucciones para ejecutar localmente.

Verifica que todo funcione antes de finalizar.
